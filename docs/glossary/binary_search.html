book_2 二分探索

print 印刷用

真ん中を見て、答えが左右どちらにあるかで範囲を半分に絞る探し方

auto_stories 解説

1〜100の数当てゲームで考えよう。

  • 全部試す：「1？2？3？…」→ 最悪100回かかる
  • 二分探索：「50より大きい？」→ 「はい」→「75より大きい？」→ … → 最悪7回で当てられる！

毎回「真ん中」を確認して半分に絞るので、N個の中から探すのに O(log N) 回で済みます。

log₂(10億) ≈ 30 なので、10億通りでもたった30回で答えが出ます。

compare 使わない場合 vs 使う場合

close 全部試す O(L) → TLE
ans = 0
# L が最大10^9 → 10億回ループ → 絶対TLE
for x in range(1, L + 1):
    if ok(x):      # 条件を満たすか確認
        ans = x
print(ans)
check 二分探索 O(log L) → 余裕で間に合う
low, high = 0, L + 1
# log2(10^9) ≈ 30 → たった30回ループ
while high - low > 1:
    mid = (low + high) // 2  # 真ん中を見る
    if ok(mid):
        low = mid   # 真ん中でOK → もっと大きくできるかも
    else:
        high = mid  # 真ん中でNG → 小さくする
print(low)

help_outline いつ使う？

「答えがxのとき条件を満たすか？」という判定ができて、「xが大きいほど難しくなる（または簡単になる）」という**単調性**があるとき。最小値の最大化・最大値の最小化問題によく登場する。
