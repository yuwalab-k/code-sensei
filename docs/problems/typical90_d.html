Cross Sum

B問題レベル 累積和配列 open_in_new AtCoderで見る print 印刷用
psychology 使う考え方：book_2 前計算（累積和）

description 問題文

$H$ 行 $W$ 列のマス目があります。上から $i$ $(1 \leq i \leq H)$ 行目、左から $j$ $(1 \leq j \leq W)$ 列目にあるマス $(i, j)$ には、整数 $A_{i,j}$ が書かれています。すべてのマス $(i, j)$ $(1 \leq i \leq H, 1 \leq j \leq W)$ について、以下の値を求めてください。

マス $(i, j)$ と同じ行または同じ列にあるマス（自分自身を含む）に書かれている整数をすべて合計した値

制約
  • $2 \leq H, W \leq 2000$
  • $1 \leq A_{i,j} \leq 99$
  • 入力は全て整数
info 入力例1を使った説明

この問題で何をするの？

3×3 のマス目（全部 1）があるとき、マス $(1,1)$ について考える。

  • 同じ 行（1行目）にあるマス：$(1,1), (1,2), (1,3)$ → 合計 3
  • 同じ 列（1列目）にあるマス：$(1,1), (2,1), (3,1)$ → 合計 3
  • $(1,1)$ 自身は両方に含まれるので 1回だけ 数える

合計は $3+3-1=5$。

入力の読み方

3 3      ← H=3行、W=3列
1 1 1    ← 1行目
1 1 1    ← 2行目
1 1 1    ← 3行目

出力の読み方

各マスの答えをスペース区切りで並べて H 行出力する。

help 制約の読み方
  • 2 ≤ H, W ≤ 2000：マスは最大 2000×2000=400万個。
  • 1 ≤ A_{i,j} ≤ 99：各マスの値は小さい（最大99）。行や列の合計は最大 99×2000=198000 程度。
  • 各マスごとに行・列を毎回足すと O(HW(H+W)) ≈ 160億回 でTLE。前計算で行の合計・列の合計を求めておけば O(HW) で済む。

この入力の意味： 3×3 のマス目で、全マスに 1 が書かれている。

マス $(1,1)$ と同じ行または列のマスは：

  • 同じ行（1行目）：$(1,1), (1,2), (1,3)$ → 合計 $1+1+1=3$
  • 同じ列（1列目）：$(1,1), (2,1), (3,1)$ → 合計 $1+1+1=3$
  • 重複する $(1,1)$ は1回だけ数える → $3+3-1=\mathbf{5}$

すべてのマスで同じ計算になるので、答えは全部 5。

lightbulb わかりやすく解説

イメージ

マス $(i, j)$ の答えは：

$$B_{i,j} = \text{(i行目の合計)} + \text{(j列目の合計)} - A_{i,j}$$

なぜ引くの？ $A_{i,j}$ は行の合計にも列の合計にも含まれているので、2回足してしまう。1回分引いて調整する。

前計算でまとめて解く

各行の合計・各列の合計を先に計算しておけば、各マスの答えは足し算と引き算だけで求まる。

  • 各行の合計を計算：$O(HW)$
  • 各列の合計を計算：$O(HW)$
  • 各マスの答えを求める：$O(HW)$

全体：$O(HW)$ → 2000×2000 でも余裕で間に合う。

menu_book くわしい解説

方針

愚直に各マス $(i,j)$ ごとに行と列を走査すると $O(HW(H+W))$ かかり、2000×2000 では 約 160 億回 の操作になりTLE（時間超過）。

前計算（累積和） を使う：

  • row[i]：$i$ 行目の全要素の合計
  • col[j]：$j$ 列目の全要素の合計

を先に $O(HW)$ で求めておく。

各マス $(i,j)$ の答えは：

$$B_{i,j} = \text{row}[i] + \text{col}[j] - A_{i,j}$$

なぜ引くの？

行の合計 $\text{row}[i]$ にも列の合計 $\text{col}[j]$ にも $A_{i,j}$ が含まれている。足すと $A_{i,j}$ を2回数えてしまうので、1回引いて正しい合計にする。

計算量

  • 前計算：$O(HW)$
  • 各マスの答え：$O(HW)$
  • 全体：$O(HW)$

2000×2000 = 400万回の操作 → 十分高速。

fn main() {
    let mut input = String::new();
    io::stdin().read_to_string(&mut input).unwrap();
    let stdout = io::stdout();
    let mut out = BufWriter::new(stdout.lock());

    let mut iter = input.split_ascii_whitespace();
    let h: usize = iter.next().unwrap().parse().unwrap();
    let w: usize = iter.next().unwrap().parse().unwrap();

    let mut a = vec![vec![0i64; w]; h];
    for i in 0..h {
        for j in 0..w {
            a[i][j] = iter.next().unwrap().parse().unwrap();
        }
    }

    let row: Vec<i64> = a.iter().map(|r| r.iter().sum()).collect();
    let mut col = vec![0i64; w];
    for i in 0..h {
        for j in 0..w {
            col[j] += a[i][j];
        }
    }

    for i in 0..h {
        for j in 0..w {
            if j > 0 { write!(out, " ").unwrap(); }
