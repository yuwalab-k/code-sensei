「今この瞬間で一番よさそうな選択」を選び続ける方法

auto_stories 解説

全部の組み合わせを試さずに、「その場で最善」を選ぶだけ。

例：500円で買えるだけお菓子を買いたい。

  • 全組み合わせを試す → 組み合わせが多すぎて大変
  • 貪欲に「高いものから順に選ぶ」→ 最適な答えになる（この場合は）

ただしすべての問題で使えるわけではない。「本当にその選択で最善になるか？」を必ず確認する必要がある。

compare 使わない場合 vs 使う場合

close 全組み合わせを試す → 指数的に遅い
from itertools import combinations
# N個からK個選ぶ全パターンを試す
# C(N, K) 通り → N=100000, K=50000 では天文学的な数
for sel in combinations(range(N), K):
    score = check(sel)
    ans = max(ans, score)
