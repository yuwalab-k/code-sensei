C問題レベル 再帰バックトラッキング全探索括弧列

description 問題文

長さ $N$ の正しいカッコ列をすべて、辞書順に出力してください。

ただし、正しいカッコ列は次のように定義されています：

  • () は正しいカッコ列である
  • $S$ が正しいカッコ列であるとき、( + $S$ + ) は正しいカッコ列である
  • $S$, $T$ が正しいカッコ列であるとき、$S$ + $T$ は正しいカッコ列である
  • それ以外の文字列はすべて、正しいカッコ列でない

また、( の方が ) よりも辞書順で早いものとします。

制約
  • $1 \leq N \leq 20$
  • $N$ は整数

info 入力例1を使った説明

この問題で何をするの？

( と ) の2種類の文字だけを使って、長さ 4 の文字列を作るとします（入力例3の場合）。

ちゃんと対応しているカッコ列、つまり：

  • 左から読んで、いつでも ( の数 ≥ ) の数
  • 最後に ( と ) の数がぴったり同じ

になっているものだけを、アルファベット順（辞書順）にすべて出力する。

入力の読み方

4  ← 作りたいカッコ列の長さ

出力の読み方

条件を満たすカッコ列を1行に1つずつ出力する。この例では (()) と ()() の2つ。

help 制約の読み方

  • 1 ≤ N ≤ 8：Nは最大8。括弧の長さは最大 2×8=16文字。
  • Nが小さいので、2^16=65536通りの全探索でも間に合う。ただし再帰で丁寧に生成する方法のほうがスマート。
  • Nが大きくなると全探索は指数爆発するので、再帰（バックトラッキング）の考え方を覚えよう。

イメージ


カッコを1文字ずつ左から決めていく。

    2.

    3. 

  3. l < N/2 なら ( を追加して再帰
    4. 

  4. r < l なら ) を追加して再帰
    5. 





menu_book くわしい解説
方針


バックトラッキング（再帰的全探索） で解く。


左から1文字ずつ選んで進み、条件を満たせなくなったら戻る。


「( と ) の残り枚数」を管理しながら深さ優先探索すると、辞書順に出力できる。




なぜ辞書順になるか


再帰で ( を先に試し、その後 ) を試すため、( < ) の順番が自然に保たれる。




よくあるミス


1. N が奇数のとき出力してしまう


正しいカッコ列の長さは必ず偶数。N % 2 != 0 のときは何も出力しない。




2. ) を置ける条件を間違える


r < N/2 ではなく r < l（閉じていない ( がある）が正しい条件。

    • 

  • 辞書順出力は「小さい選択肢から先に試す」だけで自然に実現できる

code 解答コード（Python）
Python
N = int(input())  # カッコ列の長さを読み込む

# s: 今まで作った文字列
# l: 置いた '(' の数
# r: 置いた ')' の数
def solve(s, l, r):
    if len(s) == N:      # 長さが N になったら出力
        print(s)
        return
    if l < N // 2:       # まだ '(' を置ける（合計 N/2 個まで）
        solve(s + '(', l + 1, r)
    if r < l:            # 閉じていない '(' があるので ')' を置ける
        solve(s + ')', l, r + 1)

if N % 2 == 0:           # 奇数のときは正しいカッコ列が存在しない
    solve('', 0, 0)
sentiment_dissatisfied 悪い例（結果は合ってるけど…）
O(2^(2N)×N) 全探索 — 全パターン生成して後から判定
from itertools import product
N = int(input())
for n in range(1, N + 1):
    # 2^(2n) 通りの文字列をすべて生成してから判定
    # n=8 のとき 2^16 = 65536 通り → ギリギリ間に合うが無駄が多い
    # 再帰で「最初から正しい括弧列だけ」を作れば余分な生成がない
    for bits in product('()', repeat=2*n):
        s = ''.join(bits)
        d = 0
        ok = True
        for c in s:
            d += 1 if c == '(' else -1
            if d < 0:  # 途中でマイナスになったら無効
                ok = False
                break
        if ok and d == 0:  # 最後に0になれば有効
            print(s)
