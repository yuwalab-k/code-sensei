解説

    

      

        

          
💡 カギは「木の直径」

          
一番遠い2つの都市の間に道を1本引けば、その間を往復するループができる。

          
コースの長さ ＝ 木の直径 + 1（引いた1本の道路分）

          
だから「木の直径」を求めれば解ける！

        

        

          
🔑 木の直径を求める方法

          
BFS を2回 するだけで O(N) で求まる：

          
① どこか1つの都市（例：都市1）から BFS

          
② 一番遠かった都市 u から再び BFS

          
③ その最遠距離が直径！

          
なぜこれで正しいの？木には「一番遠い都市（直径の端点）は端から BFS すると必ず見つかる」という性質がある。

        

      

      

        

          
❌ 悪い方法：全都市からBFS（O(N²)）

          
すべての都市を出発点にして BFS → 一番遠い距離を求める。

          
N=10万のとき：10万 × 10万 = 100億回 の計算 → TLE

        

        

          
✓ 正しい方法：BFS 2回（O(N)）

          
N=10万でも BFS 2回なら 20万回 の計算で済む！

          
直径の端点は「任意の点から BFS した最遠点」になるという性質を利用。

        

        

          
例1 の確認（N=3、1-2-3）

          
都市1からBFS → 都市3が最遠（距離2）

          
都市3からBFS → 都市1が最遠（距離2）

          
直径 = 2。答え = 直径 + 1 = 3 ✓

まちがい：全都市から BFS（O(N²)）

    

      

        
from collections import deque
import sys
input = sys.stdin.readline

N = int(input())
g = [[] for _ in range(N + 1)]
for _ in range(N - 1):
    a, b = map(int, input().split())
    g[a].append(b)
    g[b].append(a)

def bfs(s):
    d = [-1] * (N + 1)
    d[s] = 0
    q = deque([s])
    while q:
        v = q.popleft()
        for u in g[v]:
            if d[u] < 0:
                d[u] = d[v] + 1
                q.append(u)
    return d

ans = 0
# 全頂点からBFSしている → O(N²) でTLE
# N=10万のとき 10万×10万=100億回の計算になる！
for i in range(1, N + 1):
    ans = max(ans, max(bfs(i)[1:]))
print(ans + 1)

        

          
問題点

          
N=10万の場合、BFSを10万回実行

          
合計 10万×10万＝100億回の計算 → TLE

          
正しいアルゴリズムは BFS 2回だけで済む

import sys
from collections import deque
input = sys.stdin.readline  # 高速入力

def bfs(start, graph, n):
    dist = [-1] * (n + 1)   # -1 は未訪問
    dist[start] = 0
    q = deque([start])
    farthest = start
    max_dist = 0

    while q:
        v = q.popleft()
        for u in graph[v]:
            if dist[u] == -1:           # 未訪問なら
                dist[u] = dist[v] + 1   # 距離を記録
                q.append(u)
                if dist[u] > max_dist:  # 最遠点を更新
                    max_dist = dist[u]
                    farthest = u

    return farthest, max_dist

N = int(input())
graph = [[] for _ in range(N + 1)]

for _ in range(N - 1):
    a, b = map(int, input().split())
    graph[a].append(b)
    graph[b].append(a)

# 1回目：都市1から最も遠い都市を探す
u, _ = bfs(1, graph, N)

# 2回目：その都市から最も遠い都市を探す = 直径
_, diameter = bfs(u, graph, N)

print(diameter + 1)  # 直径 + 追加する道1本
