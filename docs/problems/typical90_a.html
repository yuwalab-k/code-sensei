解説

    

      

        
遅い方法：1cm から全部試す

        
「1cm 以上にできる？」「2cm 以上にできる？」… と L cm まで全部試す。

        
L は最大 10億。10億回も試すと何時間もかかる。

        

          
L の大きさ試す回数

          
1,0001,000 回

          
100万100万 回

          
10億10億 回（TLE!）

        

      

      

        
速い方法：二分探索（真ん中から試す）

        
「全ピースを ○cm 以上 にできる？」に変える。

        
○が大きすぎると「できない」、小さすぎると「できる」。

        
→ 境目 を真ん中から探せば 約30回 で終わる！

        

          
試す回数残り範囲

          
1回10億 → 5億

          
10回5億 → 約50万

          
30回→ 答え！

        

      

      

        
例1：L=34cm、切れ目=8・13・26cm、K=1

        
「17cm 以上にできる？」→ できない（どこで切っても片方が足りない）

        
「8cm 以上にできる？」→ できる（8cmで切ると 8cm と 26cm）

        
「12cm 以上にできる？」→ できる（13cmで切ると 13cm と 21cm）

        
「14cm 以上にできる？」→ できない

        
「13cm 以上にできる？」→ できる（13cmで切ると 13cm と 21cm）

        
「できる」の最大 ＝ 13cm → 答え！

      

      

        
「できるか」の確認方法（貪欲法）

        
「全ピースを ○cm 以上 にできるか？」は左から順番にチェック。

        
切れ目を左から見て、○cm 以上になったらすぐ切る。

        
K 回切れたら「できる」、K 回未満なら「できない」。

        
「早めに切る」のが最善。後ろに余裕が残るから。

まちがい：1から全部試す（遅い）

    

      
N, L = map(int, input().split())
K = int(input())
A = list(map(int, input().split()))

def can_cut(min_len):
    prev = 0
    cuts = 0
    for a in A:
        if a - prev >= min_len and L - a >= min_len:
            cuts += 1
            prev = a
    return cuts >= K

ans = 0
# ↓ L が最大10億なのに1から全部試す → TLE
for x in range(1, L + 1):
    if can_cut(x):
        ans = x
print(ans)

■ STAGE 6 / 6

    
正解コード

    

      

        
N, L = map(int, input().split())
K = int(input())
A = list(map(int, input().split()))

# 「全ピースを x cm 以上にできるか」を確認する関数
def check(x):
    prev = 0   # 直前に切った位置
    cnt = 0    # 切った回数
    for a in A:
        # a-prev：このピースの長さ
        # L-a：最後のピースの長さ
        if a - prev >= x and L - a >= x:
            cnt += 1   # 切る
            prev = a   # 位置を更新
    return cnt >= K    # K回以上切れればOK

low = 0       # できる側（この値以上は確実に可能）
high = L + 1  # できない側（この値以上は不可能）

# 二分探索：範囲が 1 になるまで絞る
while high - low > 1:
    mid = (low + high) // 2
    if check(mid):
        low = mid    # できた → もっと大きい値を試す
    else:
        high = mid   # できない → 小さい値を試す

print(low)   # low が答え（最大スコア）

        

          
ポイント

          
check(x)：貪欲に左から切っていく

          
二分探索：low〜high を半分ずつ絞る

          
計算量：O(N log L) — 最大約 170万回
