解説

    

      

        

          
❌ 全部書き出すのは無理

          
N=1018 のとき作れる数は 9の(10京)乗 通り。

          
宇宙の原子の総数（約1080）よりはるかに多い。

          
全パターン列挙は不可能！

        

        

          
💡 「余り」だけ追いかける（DP）

          
今まで決めた桁を B で割った 余りだけ 覚えれば十分。

          
余り r の数に桁 d を追加すると：

          
新余り = (r × 10 + d) mod B

          
余りは 0〜B-1 の B 通りしかない。DP テーブルは常に B 個だけ！

        

      

      

        

          
🔑 N が巨大でも解ける「行列累乗」

          
「1桁ずつ追加する DP」を N 回繰り返せば答えが出る。

          
でも N=1018 のとき N 回ループは無理。

          
この DP の「1ステップ」は 行列の掛け算 で表せる。

          
行列の N 乗は 繰り返し二乗法 で約60回の掛け算に圧縮！

          
1018 を2進数で表すと約60桁 → 60回の行列掛け算で解ける

        

        

          
✓ まとめ

          
① 余りの遷移を B×B の行列 T で表す

          
② 1桁の DP ベクトル v を用意

          
③ TN-1 × v を繰り返し二乗法で計算

          
④ 結果の「余り0」の成分が答え

まちがい：1桁ずつループ（N=1018 で無限ループ）

    

      

        
import sys
input = sys.stdin.readline

MOD = 10**9 + 7
N, B, K = map(int, input().split())
digits = list(map(int, input().split()))

# dp[r] = 今まで決めた桁で余りが r になる数の個数
dp = [0] * B
for d in digits:
    dp[d % B] += 1

# 1桁ずつ追加する ← N が最大 10^18 なのに 1ずつループ！
# N=10^18 のとき、このループは 10^18 回まわる
# コンピューターでも 何億年 もかかる（絶対に TLE）
for _ in range(N - 1):
    new_dp = [0] * B
    for r in range(B):
        if dp[r] == 0:
            continue
        for d in digits:
            nr = (r * 10 + d) % B
            new_dp[nr] = (new_dp[nr] + dp[r]) % MOD
    dp = new_dp

print(dp[0])

        

          
問題点

          
N=1018 のとき 1018 回ループが必要

          
コンピューターでも約30億年かかる

          
DP のステップを行列で表せば約60回で解ける

        

      

      

        

          
遷移行列 T（B=7, 数字={1,4,9}）

          

          

            T[r'][r] = 余り r に桁を加えて余り r' になる桁の個数

            シアン: 非ゼロ（遷移が存在する）
          

        

        

          
繰り返し二乗法のイメージ

          

            M8 を計算するとき：

            普通: M×M×M×M×M×M×M×M = 7回

            二乗法: M→M²→M⁴→M⁸ = 3回だけ

            

            M10^18 → 約60回 で計算できる！

正解コード

    

      

        
import sys
input = sys.stdin.readline

MOD = 10**9 + 7

def mat_mul(A, B_mat, mod, size):
    C = [[0]*size for _ in range(size)]
    for i in range(size):
        for k in range(size):
            if A[i][k] == 0:
                continue
            for j in range(size):
                C[i][j] = (C[i][j] + A[i][k] * B_mat[k][j]) % mod
    return C

def mat_pow(M, p, mod, size):
    # 単位行列から始める（掛けても変わらない）
    result = [[1 if i==j else 0 for j in range(size)] for i in range(size)]
    while p > 0:
        if p & 1:   # p が奇数なら掛ける
            result = mat_mul(result, M, mod, size)
        M = mat_mul(M, M, mod, size)  # M を 2 乗
        p >>= 1     # p を半分にする
    return result

N, B, K = map(int, input().split())
digits = list(map(int, input().split()))

# 遷移行列を作る
T = [[0]*B for _ in range(B)]
for r in range(B):
    for d in digits:
        nr = (r * 10 + d) % B
        T[nr][r] += 1

# 1桁のベクトル
v = [0] * B
for d in digits:
    v[d % B] += 1

if N == 1:
    print(v[0] % MOD)
else:
    TN = mat_pow(T, N - 1, MOD, B)
    ans = 0
    for j in range(B):
        ans = (ans + TN[0][j] * v[j]) % MOD
    print(ans)
