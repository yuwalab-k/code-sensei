問題の解説

      

        

          
▶ まず、何をすればいいの？

          
各マス (i, j) を1つずつ見ていく

          
同じ行にある数を全部足す

          
同じ列にある数も全部足す

          
自分自身は2回足してしまうので1回引く

          
それを全マスぶん繰り返す

        

        

          

            

              
毎回計算すると遅い！

              
マスの数 → 2000×2000 = 400万個

              
1マスに H+W 回の計算が必要

              
→ 全体で 160億回 → TLE ✗

            

          

          

            

              
前計算で速くする ✓

              
先に各行・各列の合計を計算して覚えておけば…

              B[i][j] = row[i] + col[j] − A[i][j]
              
Q. なぜ引く？ A[i][j] は行にも列にも入るので2回足してしまう → 1回引く

間違った回答（遅いコード）

      

        
        


H, W = map(int, input().split())
A = [list(map(int, input().split()))
     for _ in range(H)]

for i in range(H):
    row_out = []
    for j in range(W):
        s = 0
        for k in range(W):   # 行を毎回足す
            s += A[i][k]
        for k in range(H):   # 列を毎回足す
            s += A[k][j]
        s -= A[i][j]
        row_out.append(s)
    print(' '.join(map(str, row_out)))

毎回 列を全部ループして足す = H 回

正解の回答

      

        
        


H, W = map(int, input().split())
A = [list(map(int, input().split()))
     for _ in range(H)]

# 前計算：行の合計
row = [sum(A[i]) for i in range(H)]

# 前計算：列の合計
col = [sum(A[i][j] for i in range(H))
       for j in range(W)]

# 各マスを出力
for i in range(H):
    print(' '.join(
        str(row[i] + col[j] - A[i][j])
        for j in range(W)))

          

            
ポイントまとめ

            
行・列の合計を先に前計算

            
B[i][j] = row[i] + col[j] − A[i][j]

            
A[i][j] を引くのは2重カウント防止

            
計算量 O(HW) → 400万回で余裕 ✓
