book_2 木の直径

print 印刷用

木の中で一番遠い2つの点の間の距離

auto_stories 解説

木の**直径（diameter）**とは、木に含まれるすべての2点ペアの中で、距離が最も長いもの。

求め方（BFSを2回するだけ！）

  1. 適当な点sからBFSして、一番遠い点uを見つける
  2. uからBFSして、一番遠い点vを見つける
  3. u〜v間の距離が木の直径

なぜ2回で正しく求まるのかは数学的に証明できる。競プロでは「このアルゴリズムで正しい」と覚えておけばOK。

compare 使わない場合 vs 使う場合

close 全ペアの距離を計算 → O(N²)
ans = 0
# 全頂点を出発点にして最遠点を探す
# N=100000 のとき O(N²) = 100億回 → TLE
for i in range(1, N + 1):
    d = bfs(i)
    ans = max(ans, max(d[1:]))
check BFS 2回で O(N)
# 1回目：点1（どこでもいい）からBFS
d1 = bfs(1)
u = d1.index(max(d1[1:]), 1)  # 最遠点u

# 2回目：uからBFS
d2 = bfs(u)
diameter = max(d2[1:])         # 直径

# この問題では直径の道に辺を1本追加するので +1
print(diameter + 1)
