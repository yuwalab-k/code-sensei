auto_stories 解説

「クラス全員の点数の合計は？」を先生に何度も聞かれるとき：

  • 毎回足す：1回あたり N 回の計算 × Q回 = N×Q 回
  • 先に計算しておく：最初に1回 N 回の計算 → あとは答えを返すだけ = N + Q 回

N = Q = 100,000 のとき：

  • 毎回計算 → 100億回 → TLE
  • 前計算 → 20万回 → 余裕

**累積和（prefix sum）**はその応用で、「区間の合計」を O(1) で答えられるようにする。

compare 使わない場合 vs 使う場合

close 毎回合計を計算する → O(HW(H+W))
for i in range(H):
    for j in range(W):
        # 毎回この行を全部足す → O(W)
        row_sum = sum(A[i])
        # 毎回この列を全部足す → O(H)
        col_sum = sum(A[k][j] for k in range(H))
        # 合計 O(H+W) × HW マス = O(HW(H+W)) → TLE
        print(row_sum + col_sum - A[i][j])
check 先に行・列の合計を計算 → O(HW)
# 前計算：O(HW) で行の合計・列の合計を求める
row = [sum(A[i]) for i in range(H)]           # 各行の合計
col = [sum(A[i][j] for i in range(H))         # 各列の合計
       for j in range(W)]

# 各マスの答えを O(1) で計算
for i in range(H):
    print(' '.join(
        str(row[i] + col[j] - A[i][j])  # A[i][j]は2回足されるので1回引く
        for j in range(W)
    ))
