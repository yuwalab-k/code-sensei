解説

    

      

        

          
💡 考え方：1文字ずつ左から決める

          
N=4 のとき、4文字を左から1文字ずつ選ぶ。

          
( を置ける条件：まだ N/2 個未満しか置いていない

          
) を置ける条件：今まで置いた ( より少ない

          
これ以外の場合は 行き止まり → 引き返して別の選択を試す

          
（「引き返して試す」のがバックトラッキング）

        

        

          
🌳 N=4 の探索ツリー

          

                '' (l=0, r=0)

               ↓ '(' を置く

              '(' (l=1, r=0)

              ↙      ↘

            '(('       '()'

              ↓          ↙

            '(()'     '()('

              ↓          ↓

            '(())'✓   '()()'✓
          

        

      

      

        

          
❌ 悪い方法：全パターン生成してからチェック

          
N=4 なら 24=16 通り すべて生成してから正しいか確認。

          
N=20 なら 220=約100万通り。無駄が多い。

          
最初から正しい列だけ作れば、無駄なく速い。

        

        

          
✓ 再帰で「正しい列だけ」を作る

          
正しくなれないと分かった時点で引き返す。

          
N=4 の答えは 2通り だけ。16通りのうち14通りは無駄。

          
再帰を使えば最初から2通りだけ生成できる！

          
N=20 の答えも 48620 通り（約5万）= 高速に動作

        

        

          
🔑 アルゴリズムのポイント

          
変数 l（左カッコの数）と r（右カッコの数）を持ち歩く。

          
l < N/2 なら ( を足して再帰

          
r < l なら ) を足して再帰

          
長さ N になったら出力

まちがい：全パターン生成してチェック（無駄が多い）

    

      

        
from itertools import product
N = int(input())
# 全パターン（2^N 通り）生成してからチェック
for bits in product('()', repeat=N):
    s = ''.join(bits)
    depth = 0
    ok = True
    for c in s:
        depth += 1 if c == '(' else -1
        if depth < 0:  # 途中でマイナスになったら無効
            ok = False
            break
    if ok and depth == 0:
        print(s)

正解コード

    

      

        
N = int(input())

# s: 今まで作った文字列
# l: 置いた '(' の数
# r: 置いた ')' の数
def solve(s, l, r):
    if len(s) == N:    # 長さがNになったら出力
        print(s)
        return
    if l < N // 2:     # まだ '(' を置ける
        solve(s + '(', l + 1, r)
    if r < l:          # 閉じていない '(' があれば ')' を置ける
        solve(s + ')', l, r + 1)

if N % 2 == 0:         # 奇数のとき正しいカッコ列は存在しない
    solve('', 0, 0)

        

          
ポイント

          
l < N//2 のとき '(' を追加して再帰

          
r < l のとき ')' を追加して再帰

          
条件が満たせなければ自動的に引き返す

          
辞書順：'(' の方が ')' より前なので自然に達成
